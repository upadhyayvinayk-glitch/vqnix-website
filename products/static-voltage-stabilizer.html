Static Voltage Stabilizers

Electronic-speed voltage regulation using solid-state converters.

Engineering Overview

VQNIX static stabilizers use IGBT-based AC–AC PWM converters to correct voltage disturbances within a single AC cycle.

  • Response time < 10 ms
  • No mechanical components
  • High efficiency & reliability
  • Designed for critical loads
